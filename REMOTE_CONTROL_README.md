# Remote Control v1

В этой папке собран первый рабочий контур:

- `config.json` — единый источник значений;
- `index.html` — сайт читает тот же JSON;
- `admin.html` — мобильный пульт редактирования и проверки;
- `REMOTE_CONTROL_V1.md` — карта возможностей текущего APK;
- `REMOTE_CONFIG_PUBLISH_API.example.js` — пример защищённого backend-публикатора.

## Что уже синхронизировано с сайтом

1. Версия приложения — футер и schema.org.
2. Максимум отслеживаемых товаров.
3. Период истории.
4. Telegram / MAX / RuStore.
5. Юридические ссылки.
6. Баннер объявления.
7. SEO title/description/OG image.
8. Год футера.

## Почему publish API пока отдельный

Публичный браузер не должен содержать GitHub token. Поэтому кнопка «Опубликовать» в интерфейсе сейчас показывает итоговый JSON, а безопасная публикация должна идти через серверный endpoint/Cloudflare Worker, который хранит секрет GitHub на сервере.

После подключения endpoint сценарий будет:

Телефон → admin.html → защищённый API → GitHub → config.json → Android + сайт.

## Следующий шаг

Нужно один раз определить, где лежит production `config.json` (GitHub repository + branch/path). После этого backend можно привязать к реальному репозиторию без изменения APK 2.0.0.
